# 山东龙马物联网科技有限责任公司 AI 应用服务商业计划书

（v1.0 · 2026 年 9 月 ）

***

## 一、公司概况

山东龙马物联网科技有限责任公司（以下简称“公司”）为人工智能应用服务企业，面向政企及行业客户提供 AI 应用产品与技术服务。公司业务覆盖五条线：

| 业务线           | 性质           | 状态       |
| ------------- | ------------ | -------- |
| 龙马智能体（LongMa） | 自研标准化产品（端侧）  | 已商用，持续迭代 |
| 龙马工作流智能体      | 自研平台型产品（服务侧） | 已商用      |
| AI 应用定制开发     | 项目制交付        | 已有交付案例   |
| 行业 AI 解决方案    | 场景化打包方案      | 已有落地场景   |
| AI 技术服务与培训    | 服务性收入        | 持续开展     |

公司定位：**企业 AI 应用“端云一体”产品与交付伙伴**——端侧以龙马智能体触达员工桌面，服务侧以龙马工作流智能体承载企业流程与知识，辅以定制开发与技术服务满足行业个性化需求。

## 二、行业背景与市场分析

### （一）企业 AI 应用需求持续扩大

中国企业 AI 应用市场规模 2026 年约 2,000 亿元，年增速 35% 以上企业需求由“尝鲜试用”转入“生产环节实质替代人工”。

### （二）落地存在三类刚性约束

1. **数据安全约束**：政企、金融、医疗、制造等行业对数据出域高度敏感，公有云 SaaS 模式在这些行业受阻；
2. **使用习惯约束**：要求员工改用新工具的 AI 产品活跃留存普遍不足 20%〔待补：引用第三方数据〕；
3. **供应安全约束**：大模型市场格局未定，企业对单一厂商绑定存在成本与政策双重顾虑。

上述约束构成本公司产品的市场切入点：**本地与私有化部署、嵌入既有办公通道、多模型中立**。

## 三、核心产品体系

公司形成“端侧 + 服务侧”双产品矩阵，分别解决“员工如何用 AI”与“企业流程如何嵌入 AI”两个层面的问题。

### （一）龙马智能体（端侧产品）

部署于企业办公电脑的本地化 AI 助手，具备四项核心能力：

1. **智能对话与文档处理**：多会话管理、流式输出、图像理解、PDF/Word 文档解析；
2. **流程自动化**：浏览器自动化（网页阅读、表单填写、数据采集）与电脑操作（截屏—理解—执行闭环）；
3. **即时通讯集成**：接入企业微信、钉钉、飞书、个人微信，员工在既有聊天窗口内直接调用；
4. **多模型接入（BYOK）**：内置 30 余家主流大模型厂商接入配置，企业使用自有 API 账户，模型可随时切换。

技术要点：

| 特性    | 实现方式                              | 客户价值             |
| ----- | --------------------------------- | ---------------- |
| 数据本地化 | 会话与业务数据存本机数据库，密钥存操作系统凭据库，无云端用户数据库 | 数据不出企业，满足合规要求    |
| 全渠道嵌入 | 四大 IM 平台机器人协议直连                   | 零新增软件，员工无学习成本    |
| 模型中立  | BYOK 架构，平台不加价、不抽成                 | 模型成本由企业自主掌控      |
| 白标输出  | 构建期品牌体系（名称、标识、更新源）可整体定制           | 支持合作伙伴快速推出自有品牌产品 |

### （二）龙马工作流智能体（服务侧平台）

面向企业流程智能化与知识资产管理的人工智能应用开发与运行平台，支持企业以低代码方式构建、编排、运行 AI 应用，核心能力包括：

1. **可视化工作流编排**：拖拽式节点编排（大模型调用、条件分支、工具调用、代码执行、HTTP 集成），业务人员零代码即可将 AI 能力嵌入业务流程；
2. **企业知识库引擎（RAG）**：文档批量导入、自动切分与向量化、检索增强生成，实现企业私有知识的可问答、可复用，构建组织级知识资产；
3. **多智能体编排**：支持多角色智能体分工协作，承载跨部门、多步骤的复杂业务流程；
4. **统一模型接入**：聚合国内外主流大模型，统一调度、统一计量，与企业既有模型账户体系对接；
5. **应用快速发布**：编排完成的流程可一键发布为 Web 应用、API 接口或嵌入业务系统，缩短 AI 应用交付周期；
6. **私有化部署**：支持企业内网独立部署，知识库数据、流程配置、调用日志全程留在企业环境内。

### （三）产品矩阵协同

| 维度   | 龙马智能体        | 龙马工作流智能体          |
| ---- | ------------ | ----------------- |
| 部署位置 | 员工办公终端       | 企业服务器/私有云         |
| 解决问题 | 员工个人生产力      | 企业流程与知识资产         |
| 使用入口 | 桌面客户端、IM 聊天窗 | Web 应用、API、业务系统集成 |
| 数据边界 | 本机存储         | 私有化部署             |

两端协同形成闭环：工作流平台沉淀企业知识与流程，通过 API 供端侧智能体调用；端侧智能体采集的一线业务场景，反哺平台流程优化。该“端云一体”结构为公司区别于单一工具型厂商的核心产品形态。

## 四、业务体系

### （一）产品线收入

1. **龙马智能体**：企业版按席位年度订阅；白标 OEM 按项目授权并收取年度维护费；
2. **龙马工作流智能体**：私有化部署授权费 + 按规模年度订阅〔待补定价〕；知识库建设与流程编排实施服务按项目计费。

## 五、商业模式

| 层级 | 模式            | 定价参考〔待补〕  | 作用        |
| -- | ------------- | --------- | --------- |
| L1 | 产品订阅（双产品线）    | 按席位/规模/年  | 现金流基本盘    |
| L2 | 白标 OEM 与私有化授权 | 按项目 + 年维护 | 核心增长引擎    |
| L3 | 定制开发与行业方案     | 项目制       | 高毛利、树标杆   |
| L4 | 技术服务与培训       | 人天计费      | 客户粘性与获客入口 |

**增长逻辑**：以 L3/L4 切入获取客户与场景认知，沉淀为 L1 订阅；L2 白标与私有化授权借助合作伙伴及行业渠道实现规模复制。龙马智能体已完成“一套代码、多品牌交付”工程架构，龙马工作流智能体支持标准化私有化交付，两者边际交付成本均趋近于零。

## 六、竞争优势

1. **端云一体产品矩阵**：同时覆盖员工端生产力与企业端流程知识，单点厂商难以对位竞争；
2. **工程整合壁垒**：多模型适配、浏览器与电脑自动化、IM 全通道、本地数据架构、低代码编排平台六项能力的整合交付，同类竞争者补齐周期以年计；
3. **交付速度**：从立项到双品牌商用发布历时数月，保持周级迭代（已发布 12 个版本）；
4. **白标与私有化体系**：可复制的品牌输出与私有化交付流水线，已在独立品牌上验证；
5. **厂商中立**：不绑定任何大模型厂商，与客户利益一致；
6. **合规适配**：本地优先与私有化架构顺应数据安全监管趋势，政策收紧扩大公司目标市场。
