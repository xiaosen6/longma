# Social · 使用说明书

> 技能名：**Social**。对着 Work Buddy 说话，把视频和图文发到公司账号。  
> 不用开终端，不用记命令，说清楚「发到哪个号、发什么」即可。

## 1. 它能干什么

| 你想做的事 | 跟智能体怎么开口 |
| --- | --- |
| 看看公司有哪些号 | 「有哪些号可以发？」 |
| 看某个号还能不能用 | 「品牌抖音还能用吗？」 |
| 扫码登录 | 「登录品牌抖音」 |
| 发一条视频 | 「这个视频发到品牌抖音，标题是……」 |
| 发一组图文 | 「这几张图发到品牌小红书，标题是……」 |
| 约好时间再发 | 「明天下午 6 点发，不要现在发」 |
| 同时发几个平台 | 「同步发到品牌抖音和品牌小红书」 |

支持的平台：

- 抖音、快手、小红书：视频 + 图文
- B 站、视频号、YouTube：目前只支持视频

不支持：百家号、TikTok。需要的话请走人工或找技术。

## 2. 开始之前

请确认这三件事已经由技术做好（综合部不用自己装）：

1. 这台电脑已安装 **Work Buddy**
2. 已导入技能 **Social**（`social.zip`）
3. 已填好公司账号对照表（`accounts.yaml`）

对照表里会写好口语称呼，例如「品牌抖音」「品牌小红书」。你日常就用这些称呼，不必记英文账号名。

> **提示**  
> 发布发生在**这台电脑**上。登录要扫码时，人要在电脑旁。不要指望在另一台手机里远程完成首次登录。

## 3. 怎么跟智能体说话

一句话里尽量带齐四件事，智能体就能少问一轮：

```text
发到哪个号  +  发什么文件  +  标题  +  现在发还是定时
```

### 3.1 把文件给它

任选一种即可：

- 把视频 / 图片**拖进 Work Buddy 对话**
- 或写出完整路径，例如 `D:\素材\三月活动\成片.mp4`
- 多张图一次拖进去，并说明顺序（封面图请单独说）

### 3.2 用对照表里的称呼

说「品牌抖音」，不要说 `douyin brand`。

如果公司后来加了新号，让技术写进对照表，你就可以直接喊新称呼。

### 3.3 标题、简介、标签分开说

| 字段 | 你怎么说 | 说明 |
| --- | --- | --- |
| 标题 | 「标题是：春日上新」 | 必填。抖音标题建议不超过 30 字 |
| 简介 / 正文 | 「简介写：……」或「笔记正文是：……」 | 视频叫简介，图文叫正文。B 站简介必填 |
| 标签 | 「标签：春日、上新、穿搭」 | 没有就不用说。小红书最多 10 个 |
| 封面 | 「封面用这张图」 | 可选 |
| 定时 | 「2026-08-20 18:00 发」 | 必须比现在晚至少 **2 小时** |
| 草稿 | 「先存视频号草稿，别发出去」 | 目前只有视频号支持草稿 |

### 3.4 一次说一个意图最稳

先登录、再检查、再发布，比一句里塞三件事更不容易出错。

可以分三条发：

```text
1. 登录品牌抖音
2. 品牌抖音还能用吗
3. 这个视频发到品牌抖音，标题是春日上新，现在发
```

### 3.5 智能体问什么，就补什么

它缺信息时会问，不要让它「先猜一个标题发了」。你补一句即可，例如：

- 「标题用：办公室的一天」
- 「不要定时，现在发」
- 「就发品牌抖音，别的号先不动」

## 4. 常用说法（可直接复制）

把「品牌抖音」换成你们对照表里的真实称呼。

### 查号

```text
有哪些号可以发？
```

```text
品牌抖音还能用吗？
```

```text
帮我检查品牌小红书和品牌视频号
```

### 登录

```text
登录品牌抖音
```

```text
品牌小红书过期了，重新扫码
```

```text
登录品牌YouTube（会弹出浏览器，我在窗口里登 Google 账号）
```

### 发视频

```text
这个视频发到品牌抖音。
标题：春日上新
简介：门店新品到了，欢迎来试。
标签：春日,上新
现在发。
```

```text
把 D:\素材\成片.mp4 发到品牌快手，
标题用「周末探店」，现在发。
```

### 发图文

```text
这 4 张图发到品牌小红书。
标题：办公室午餐日记
正文：今天试了新的轻食搭配。
标签：午餐,办公室
现在发。
```

### 定时

```text
这个视频发到品牌抖音，
标题：周五直播预告，
2026-08-21 18:00 发，不要现在发。
```

> 定时必须晚于当前时间 2 小时以上。  
> 「明天发」请补钟点，例如「明天下午 6 点」。

### 多平台

```text
同一条视频，同步发到品牌抖音和品牌小红书。
标题都用「春日上新」，现在发。
```

```text
先发品牌抖音；品牌小红书等我说再发。
```

### 视频号草稿 / YouTube 可见性

```text
发到品牌视频号，先存草稿，不要公开。
标题：活动花絮
```

```text
发到品牌YouTube，
标题：Spring Lookbook，
可见性：不公开。
```

### 中途改主意

```text
先别发，我改一下标题。
```

```text
取消定时，改成立即发。
```

```text
只发抖音，小红书这次不要发。
```

## 5. 完整对话示例

下面是一次标准发布。智能体的回复仅作示意，以实际对话为准。

**你**

> Social。这个视频发到品牌抖音，标题是春日上新，现在发。

**智能体**

> 即将发布：  
> - 账号：品牌抖音（抖音）  
> - 类型：视频  
> - 文件：成片.mp4  
> - 标题：春日上新  
> - 简介或正文：无  
> - 时间：立即  
> 请回复「确认」后开始。

**你**

> 确认

**智能体**

> 已提交到品牌抖音。平台还要审核，不保证马上能刷到。

---

如果号过期了，中间会多一轮登录：

**智能体**

> 品牌抖音要重新扫码。请用抖音 App 扫描下面的二维码。

（此处应直接出现二维码图片）

**你**

> 扫好了

**智能体**

> 登录完成。按刚才的内容重新确认后就可以发。

---

如果抖音弹出短信验证：

**智能体**

> 抖音要短信验证码。手机收到 6 位数字后发给我。

**你**

> 482916

**智能体**

> 已帮你提交验证码，继续发布。

不要在群里转发验证码。只发给当前这只智能体。

## 6. 登录与扫码

| 平台 | 你怎么配合 |
| --- | --- |
| 抖音、快手、小红书、视频号 | 智能体展示二维码（或弹出浏览器），用对应 App 扫 |
| B 站 | 需要在这台电脑的**终端**里登录，智能体会告诉你怎么做；二维码看 `qrcode.png` |
| YouTube | 弹出浏览器，在窗口里登录 Google 账号，没有二维码 |

建议：

1. 第一次用某个号，先说「登录 ×××」，不要直接发正式内容  
2. 二维码过期就再说一次「重新登录 ×××」  
3. 扫的是**该平台创作者后台**的码，不是普通看视频的码

## 7. 发布前的确认卡

智能体真正开跑前，应复述类似下面的卡片。请逐项看一眼：

```text
即将发布：
- 账号：品牌抖音（抖音）
- 类型：视频 / 图文
- 文件：……
- 标题：……
- 简介或正文：……
- 时间：立即 / 定时 2026-08-21 18:00
请回复「确认」后开始。
```

| 你回复 | 含义 |
| --- | --- |
| 确认 / 发出去 / 现在就发 | 按卡片执行 |
| 标题改成 xxx | 只改这一项，再确认一次 |
| 先别发 | 停住，不会发出去 |

账号、文件、标题、时间任何一项不对，都不要回「确认」。

## 8. 各平台能发什么

| 平台 | 视频 | 图文 | 定时 | 特别注意 |
| --- | --- | --- | --- | --- |
| 抖音 | 可以 | 可以 | 可以 | 标题建议 ≤ 30 字；图文最多 35 张，不要 GIF；可能要短信验证码 |
| 快手 | 可以 | 可以 | 可以 | 图文请用不同图片，不要同一张图重复添加 |
| 小红书 | 可以 | 可以 | 可以 | 标签最多 10 个 |
| B 站 | 可以 | 不行 | 可以 | 必须有简介和分区；登录要在本地终端完成 |
| 视频号 | 可以 | 不行 | 可以 | 可以说「先存草稿」 |
| YouTube | 可以 | 不行 | 不行 | 可指定公开 / 不公开 / 私享；可加入播放列表 |

「已提交」只表示已经交给平台，**不等于已经过审、已经能刷到**。

## 9. 智能体不会擅自做的事

请按这个预期来用，也用这些话约束它：

- 不会在你确认前发出去  
- 不会自己编标题、标签、简介  
- 不会把对照表里没有的号拿来用  
- 不会同时抢着发好几个平台（会一个一个来）  
- 不会把「明天发」理解成立刻发  
- 不会承诺「一定过审 / 马上能刷到」  

如果你发现它要加你没提过的标签或封面，直接说：

```text
不要自己加标签和封面，按我说的发。
```

## 10. 出了问题怎么办

| 你看到的情况 | 可以这样说 / 这样做 |
| --- | --- |
| 提示要重新扫码 | 「重新登录品牌抖音」，扫新码 |
| 一直等不到二维码 | 看这台电脑有没有弹出浏览器；没有就说「用有窗口的方式重新登录」 |
| 抖音要验证码 | 把短信里的数字发给智能体 |
| 找不到文件 | 把文件重新拖进对话，或给出完整路径 |
| 定时被拒绝 | 换一个比现在晚 2 小时以上的时间 |
| 说找不到发布程序 | 找技术，不要自己装 Python |
| 某一个平台失败、另一个成功 | 先记下成功的，失败的单独再说一次「只重试品牌小红书」 |

平台页面改版、风控升级时，有可能突然发不出去。这不是操作错误，把失败平台告诉技术即可。

## 11. 附录：技术第一次怎么装

综合部可跳过本节。

1. 本机按仓库文档装好 `sau` 与 Chromium  
2. 复制对照表并改成公司真实称呼：

```bash
cp skills/social/accounts.example.yaml skills/social/accounts.yaml
```

3. 将 `social.zip`（或整个 `social` 文件夹）导入 Work Buddy 技能  
4. 带综合部走通一次：登录 → 检查 → 用测试素材定时发布  

更细的步骤见同目录 [references/install.md](references/install.md)。

---

**一句话记住**

> 打开 Work Buddy，说一声 Social，把文件丢进去，再说：「发到哪个号、标题是什么、现在发还是几点发」。  
> 看完确认卡，回「确认」。
