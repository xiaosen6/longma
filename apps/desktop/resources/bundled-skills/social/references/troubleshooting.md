# 排障（对用户说人话）

先看命令 stderr / 最后几行，再按下表回复。不要把堆栈原文甩给综合部。

| 现象 | 对用户说 | 你做 |
| --- | --- | --- |
| 找不到 `sau` | 这台电脑还没装好发布程序，需要技术先装一次。 | 打开 `install.md`，按技术步骤处理，不要让综合部装 Python |
| `check` 为 `invalid`，或提示 cookie 失效/过期 | 这个号要重新扫码登录。 | 走登录流程，展示二维码 |
| 登录超时、一直等不到扫码 | 二维码可能过期了，我再开一次登录。 | 重新 `login --headed`，展示最新二维码图 |
| 找不到二维码图 | 请看这台电脑弹出的浏览器窗口，用对应 App 扫里面的码。 | 登录加 `--headed`；B 站改让用户打开 `qrcode.png` |
| B 站 login 报 not a terminal / 非交互 | B 站登录必须在这台电脑的终端里自己跑，我不能代扫。 | 给出 `sau bilibili login --account <account>`，提醒看 `qrcode.png` |
| 抖音要验证码 | 抖音要短信验证码。手机收到 6 位数字后发给我。 | 写入仓库根目录 `verify_code.txt` |
| File not found / 文件不存在 | 找不到这个文件，请把视频或图片直接发过来，或给出完整路径。 | 不要改用其它文件顶上 |
| 定时必须大于当前时间 2 小时 / 必须晚于当前 | 定时至少要比现在晚 2 小时，请换一个时间。 | 不要擅自改成立即发 |
| 小红书标签最多 10 个 | 小红书最多 10 个标签，请删掉几个。 | 不要悄悄截断 |
| B 站缺 `--tid` | B 站必须有分区。对照表有 `tid` 就用，没有就问技术。 | 不要编分区号 |
| YouTube 超时 / 连不上 | 可能访问不了 YouTube，需要技术在配置里加代理。 | 不要让综合部改 `conf.py` |
| 发布命令非 0 退出 | 这次没发上去。 | 复述失败的平台和关键原因；不要连着换参数盲试超过一次 |

登录二维码常见位置：

- 仓库 `cookies/<平台>_<account>_login_qrcode_*.png`（取最新）
- B 站：当前工作目录 `qrcode.png`

也可用 `scripts/latest_qrcode.py <仓库根目录>`。
